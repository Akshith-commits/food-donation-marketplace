# 🍱 FoodBridge — Food Donation Marketplace

**Connecting surplus food with communities in need.**

FoodBridge is a food donation marketplace prototype designed to connect food donors, NGOs, and administrators to help redirect surplus food to people who need it.

Built with a focus on a premium user experience, smooth cinematic scrolling, and a Hyderabad-focused food rescue workflow.

## ✨ Features

- **Cinematic landing page** — scroll-driven food imagery and an interactive entry experience.
- **Donor dashboard** — post surplus food, manage listings, and track donation status.
- **NGO marketplace** — discover available food donations and manage claims.
- **Donation lifecycle** — track listings from posting and claiming through pickup and delivery.
- **Admin console** — review NGO verification and monitor donation activity.
- **Hyderabad-focused data** — sample donors, NGOs, food items, and locations.
- **Responsive interface** — designed for desktop and mobile screens.
- **Glass-inspired UI** — translucent surfaces, gradients, and modern visual styling.

## 🚀 Run Locally

**Prerequisites:** Node.js and npm.

```bash
git clone https://github.com/Akshith-commits/food-donation-marketplace.git
cd food-donation-marketplace
cd client
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.

## 🏗️ Production Build

From the `client` directory, run:

```bash
npm run build
```

Vite generates the production build in `client/dist`.

## 🎯 Project Goal

FoodBridge aims to make surplus food redistribution easier by helping donors identify available food, NGOs claim donations, and administrators oversee the workflow.

## ⚠️ Prototype Notice

This repository currently represents a hackathon prototype. Sample data and simulated sign-in or workflow behaviour should not be interpreted as a production food-distribution service. Verify the current implementation before relying on any feature.
